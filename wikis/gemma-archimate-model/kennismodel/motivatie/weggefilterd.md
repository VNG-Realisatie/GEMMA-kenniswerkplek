# Motivatie — weggefilterd

<!-- Gegenereerd door tools/kennismodel.py; wijzig de bron, niet deze pagina. -->

Elementtypen van de laag Motivatie die niet tot een element van dit model leiden. Een begrip van zo'n type krijgt de uitkomst uit de beslistabel (geen pagina, of buiten dit model).

| Elementtype | In Over GEMMA | Reden |
|---|---|---|
| Doel (Goal) | Kwaliteitsdoel | Buiten dit model: een doel (armoedebestrijding) is geen beleidskader. |
| Uitkomst (Outcome) | — | Buiten dit model. |
| Principe (Principle) | Architectuurprincipe | Buiten dit model. |
| Eis (Requirement) | Requirement, Implicatie | Buiten dit model: een losse norm uit één artikel ('binnen acht weken beslissen') is een eis of beperking; de regeling als geheel is een beleidskader of blijft bron. |
| Beperking (Constraint) | Standaard | Buiten dit model, als een eis. |
| Waarde (Value) | — | Buiten dit model. |
| Kernwaarde (Driver) | Kernwaarde | Buiten dit model: een fundamentele overtuiging waaraan overheidsdienstverlening moet voldoen. Ook een Driver; alleen het beleidskader is een element. |
| Vermogen (Capability) | Capability | Buiten dit model (strategielaag): "wat de gemeente kan" is geen bedrijfsfunctie. |
| Groepering (Grouping) | Groep | Buiten dit model als begrip (een thema); de indelingen gebruiken groeperingen. |
