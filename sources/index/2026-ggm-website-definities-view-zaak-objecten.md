# GGM-website, definities: View (Zaak)objecten

## Samenvatting
Pagina van de website van het Gemeentelijk Gegevensmodel (GGM, versie latest) met de definities van het pakket View (Zaak)objecten (versie 1.3, gewijzigd 2024-11-21), een technisch pakket in de repository van het GGM en geen beleidsdomein. Het pakket heeft geen definitie. Het bevat één element RSGB zonder definitie; een view op de objecten die bij een zaak horen. Per element geeft de pagina de kenmerken en de attributen, zoals bij de deelmodellen.
