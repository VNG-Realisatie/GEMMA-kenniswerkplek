# GGM-website, definities: Diagram

## Samenvatting
Pagina van de website van het Gemeentelijk Gegevensmodel (GGM, versie latest) met de definities van het pakket Diagram (versie 1.2, gewijzigd 2025-03-27), een technisch pakket in de repository van het GGM en geen beleidsdomein. Het pakket heeft geen definitie. Het bevat één objecttype (OverigeGeoObjecten) zonder definitie. Per element geeft de pagina de kenmerken en de attributen, zoals bij de deelmodellen.
