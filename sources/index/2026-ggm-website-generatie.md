# GGM-website: Databaseschema's

## Samenvatting
Pagina over het genereren van databaseschema's uit het GGM. Vanaf release v2.4.0 is er een set kant-en-klare DDL-bestanden voor MySQL, MSSQL, Oracle en PostgreSQL, per diagram gegenereerd. Daarnaast de codegeneratietemplates voor Enterprise Architect: installeren, gebruiken, de interne werking (hoe objecttypen, attributen en relaties naar tabellen, kolommen en sleutels worden vertaald, met voorbeelden) en het zelf aanpassen van de templates in twee generatiestappen.
