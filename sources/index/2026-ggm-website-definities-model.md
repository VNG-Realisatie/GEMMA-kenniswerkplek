# GGM-website, definities: Model

## Samenvatting
Pagina van de website van het Gemeentelijk Gegevensmodel (GGM, versie latest) met de definities van het pakket Model (versie 1.0, gewijzigd 2018-05-15), een technisch pakket in de repository van het GGM en geen beleidsdomein. Het pakket heeft geen definitie. Het bevat één objecttype, Periode (bepaalde tijdsduur). Per element geeft de pagina de kenmerken en de attributen, zoals bij de deelmodellen.
